# Solana Meme Trader — бумажная торговля мемкоинами

Программа-«торговая команда» из 4 ботов, как в видео: каждый бот торгует мемкоины pump.fun своей стратегией, у каждого свой банк в SOL, раз в час худший отдаёт 50% свободных денег лучшему. Всё видно на дашборде в браузере.

**Сейчас это только PAPER TRADING (бумажная торговля).** Кошелёк не нужен, приватный ключ не нужен, реальные деньги не тратятся. Программа смотрит на реальный поток сделок pump.fun и считает, что было бы, если бы она купила/продала на Axiom — с комиссиями Axiom (1% + 1%), priority fee, Jito-bribe, задержкой исполнения и проскальзыванием.

## Запуск

1. Установите **Node.js 22 или новее**: https://nodejs.org (кнопка LTS). Больше ничего ставить не нужно — у программы нет зависимостей.
2. Скачайте репозиторий (Code → Download ZIP) и распакуйте.
3. Запустите:
   - **Windows:** двойной клик по `start-windows.bat` (живые данные) или `start-demo-windows.bat` (демо-рынок).
   - **Mac / Linux:** `./start.sh` или `./start.sh --demo`.
   - Или из терминала: `npm start` / `npm run demo`.
4. Браузер откроется сам на http://localhost:3777. Остановить — `Ctrl+C` в окне программы.

### Режимы

| Режим | Команда | Откуда данные |
|---|---|---|
| Живые данные | `npm start` | реальные новые токены и сделки pump.fun через бесплатный WebSocket [PumpPortal](https://pumpportal.fun/data-api/real-time) |
| Демо | `npm run demo` | встроенный симулятор рынка (фейковые токены, настоящая математика bonding curve) — чтобы посмотреть, как всё работает |

Флаги: `--fresh` — начать с нуля, `--no-open` — не открывать браузер, `--port 4000` — другой порт.

Состояние сохраняется в `data/state-*.json`, каждая закрытая сделка пишется в `data/trades-*.csv` (открывается в Excel).

## Команда

| Бот | Стиль | Когда покупает | Выход по умолчанию |
|---|---|---|---|
| **COLE** | momentum (скальпинг) | токену < 20 мин, за 60 сек объём ≥ 4 SOL, цена +15%, покупок в 1.5 раза больше продаж, ≥ 8 разных покупателей | TP +40%, SL −15%, трейлинг 12%, макс. 10 мин |
| **RINA** | pullbacks | был рост ≥ +80%, затем откат 25–45% от хая, и покупатели снова перевешивают | TP +35%, SL −18%, макс. 15 мин |
| **VINCE** | liquidity (final stretch) | bonding curve 40–92%, Global Fees ≥ 0.5 SOL, ≥ 40 холдеров, ликвидность в кривой за 2 мин выросла ≥ 15% | TP +50%, SL −20%, макс. 20 мин |
| **OWEN** | survivor | токену ≥ 20 мин, MC ≥ $15k, top10 ≤ 20%, снайперов ≤ 5%, просадка от хая ≤ 40%, за 10 мин цена +10% | TP +60%, SL −25%, трейлинг 20%, макс. 60 мин |

Перед любой покупкой — проверки из гайда («Как читать метрики»):
- Top 10 холдеров ≤ 25%, у дева ≤ 10%, у снайперов (купили в первые 15 сек) ≤ 15%, холдеров ≥ 15;
- **вамп-проверка**: если есть токен с тем же тикером/названием и большим MC — это не основная монета, пропускаем.

Правила риска (тоже из гайда): вход не меньше 0.05 SOL, продаём 100% позиции сразу, не больше 6 входов в час на бота, пауза 60 сек после убытка («не мсти рынку»), при просадке команды на 40% новые входы останавливаются.

Все цифры меняются в `config.local.json` — скопируйте `config.local.example.json`, переименуйте и правьте только нужное. Полный список параметров с комментариями — в `src/config.js`.

## Дашборд

- Верх: стартовый банк, баланс команды, чистый P&L, время работы; кнопки **Пауза**, **Продать всё**, **Сброс**.
- Карточки ботов: баланс, доходность за текущий час (H01, H02…), общая доходность, W/L, текущая монета. Зелёная рамка — лучший за час, красная — худший.
- TRADES: открытые позиции, что боты сейчас «смотрят» (watch) и закрытые сделки. Клик по токену открывает его на **Axiom**.
- ALLOCATION: история перераспределений и доля капитала каждого бота.
- LOG: все решения ботов с причинами.

## Важно

- Это симуляция. Реальное исполнение на горячих запусках хуже: конкуренция ботов, MEV, фейлы транзакций. Если бумажная торговля в плюсе несколько дней подряд — это повод продолжать тестировать, а не гарантия.
- Часть метрик Axiom считается приблизительно из потока сделок: Global Fees ≈ 1% объёма + средний priority fee; «Pro Traders», бандлы и соцсети пока не учитываются.
- Реальная торговля пока не реализована. У Axiom нет публичного API для ботов; для живой торговли нужен будет отдельный кошелёк и исполнение через PumpPortal/Jupiter — это следующий этап.

## Структура

```
src/
  index.js            запуск, сохранение состояния
  config.js           все настройки по умолчанию
  market.js           состояние токенов: цена, объём, холдеры, curve %
  safety.js           проверки перед входом
  paper.js            бумажное исполнение (кривая + комиссии Axiom)
  team.js             банки ботов, входы/выходы, перераспределение
  agents/             COLE, RINA, VINCE, OWEN
  feeds/pumpportal.js живые данные pump.fun
  feeds/simulator.js  демо-рынок
  server.js           локальный сервер дашборда
public/               дашборд
test/                 тесты: npm test
```
